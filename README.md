# 月光沙漏 · 江湖疫案錄 The Moonlight Hourglass: Jianghu Chronicles

A bilingual (Traditional Chinese / English) RPG for teaching epidemiologic study designs and their biases:
cross-sectional, case-control, retrospective cohort and prospective cohort.

## Files
- `index.html` – the whole game (HTML, CSS and JavaScript in one file)
- `theme.mp3` – theme song 《流行病學全掌握》 (must stay in the same folder as index.html)

## Run locally
Open `index.html` in a browser. (If music doesn't play when opening the file directly, run a local server:
`python3 -m http.server` in this folder, then visit http://localhost:8000.)

## Publish on GitHub Pages
1. Create a new public repository and upload `index.html`, `theme.mp3` and this README.
2. Settings → Pages → Build and deployment → Source: "Deploy from a branch".
3. Branch: `main`, folder: `/ (root)` → Save.
4. After a minute or two, the game is live at `https://<your-username>.github.io/<repository-name>/`.

All characters, places and data in the game are fictional.
